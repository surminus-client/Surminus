# SurMinus - Advanced Game Client

**SurMinus** is an elite browser extension client for Surviv.io, providing powerful features to enhance your gameplay experience. Forked from Surplus.

---

## ✨ Features

### 🔫 Combat Features
- **Aimbot** - Auto-targeting with sticky target, wallcheck, and visual indicators.
- **Auto Fire** - Automatic weapon firing when target is locked.
- **Auto Heal** - Smart bandage and med kit usage based on health.
- **Auto Crate Break** - Efficiency-focused crate destruction.

### 👁️ Visual Features
- **ESP (Player Detection)** - Live tracking of player positions.
- **X-Ray** - See through walls, trees, and smoke.
- **Infinite Zoom** - Unrestricted FOV control.
- **Grenade Timer** - Visual countdown for perfect throws.

### 🛠️ Utility Features
- **Auto Loot** - Automatic item prioritization and pickup.
- **Layer Spoofer** - Advanced render manipulation.
- **Keybind System** - Fully customizable hotkeys.

## 🚀 Installation

### Tampermonkey Userscript (Recommended)
1. Install **Tampermonkey** on your browser.
2. Open the dashboard and "Create New Script".
3. Paste the contents of `Surplus.user.js` and save.
4. Go to `surviv.io` and press `Shift + Right Click`.

### Chrome Extension
1. Go to `chrome://extensions/` and enable **Developer mode**.
2. Drag the `Surminus.zip` into the page.
3. Refresh the game.
